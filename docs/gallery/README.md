The polynomial reference is `T = 300 + 320 X(1-X)Y(1-Y)` K, with
`X=x/0.06` and `Y=y/0.04`. The RC reference is
`T = 300 + 10*(1-exp(-t/20))` K. The discrete RC recurrence gives
`T_n = 310 - 10*(20/21)^n` K for the plotted 1 s steps. Those formulas
provide independent checks of the plotted values. The plate's discrete
sine-mode reference and power accounting remain in the verification tests.

The finest plate error is about 0.125127 K. Maximum-error orders are about
1.60020 and 1.82593. At 20 s the discrete RC temperature is about 306.231105 K
and the analytical value about 306.321206 K. These figures show finite
numerical comparisons. They contain no physical measurements, uncertainty
bounds or device-safety evidence. See [spatial refinement](../plate_refinement.md)
and [transient energy](../transient_energy.md) for tolerances and limitations.
