# ThermalPath v0.1.0

This first numbered release packages the completed thermal calculation scope:
steady resistance paths and networks, scalar RC and backward-Euler network
transients, and small steady rectangular plates. It includes signed balance
diagnostics, independent numerical examples, bounded studies, reference-data
comparison, deterministic reports and a local Streamlit worksheet.

## Included

- SI input validation and a versioned JSON network command.
- Cellwise plate conductivity, fixed/flux/convective boundaries, broad-face
  exchange and rectangular heater overlap integration.
- Analytical, rational and discrete modal verification, with spatial/time
  refinement examples and the original adverse cases.
- Parameter sweeps, local sensitivities, seeded uniform-input studies and
  nominal candidate comparisons that retain failures.
- Provenance-bearing reference import, signed residuals and RMSE with explicit
  missing/excluded counts, and JSON/Markdown evidence export.
- A bounded three-node worksheet, submitted-case state and AppTest coverage.
- Fresh-install instructions, measured demo timings and a reproducible gallery.

The [evidence audit](../release_audit.md) maps D01-D30 to the supporting records.
The [gallery](../gallery/README.md) supplies all plotted data and hashes.

## Numerical behavior

The steady solver attempts at most one correction using original link balances.
It retains the direct solution if the candidate is invalid or does not strictly
reduce the largest physical residual. This repaired two retained worksheet
reference failures without changing the 2e-10 K/W acceptance screens. It is
not a general accuracy guarantee. No solver source changed during release
preparation; see [D28](../devlog/day28.md) for the complete before/after evidence.

## Installation and compatibility

Use the source archive or checkout with Python 3.12 and the included
`requirements-dev.lock`, following [reproducibility](../reproducibility.md).
The wheel contains the library and CLI; examples, tests, documents and the
worksheet are in the source archive. The optional `app` extra requires
Streamlit. Version-1 network JSON is retained. This release does not publish
to a package registry, add a hosted service, or promise stable APIs beyond
the documented 0.1.0 contract.

## Limits

All bundled thermal examples use synthetic inputs. Numerical agreement,
balance closure, passing tests and successful installation do not establish
physical validation or device safety. The heat-spreader recommendation is
conditional on its two stated cases and ideal cooling boundaries. Dense
solves target small problems; extreme conditioning and floating-point range
limits remain. See [limitations](../limitations.md) before using results for
engineering decisions.

The release tag identifies the delivered source, and the GitHub release records
the exact-commit CI outcome. The source audit is dated 2026-10-26; publication
status must be read from the actual tag/release rather than inferred from this file.
