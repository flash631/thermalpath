# Release evidence and version 0.1.0

Close the existing thirty-increment scope without adding a thermal model or
changing acceptance criteria. Audit current claims against source, independent
references, recorded executions and limitations. Keep dated records as historical
observations, including the D28 numerical failures and their bounded correction.

Use the existing plotting example for the README gallery. Retain full plotted
inputs and hashes, physical axes, common color limits and the measured lower
maximum-error orders. Check the continuum plate samples with exact fractions,
the RC recurrence with exact rational powers, and analytical RC values with
70-digit decimal arithmetic. Inspect the actual PNGs before distribution.

Version 0.1.0 changes metadata and evidence presentation only. Keep the JSON
schema, solver source, dependency lock and all numerical thresholds unchanged.
The release contains a source archive and wheel; there is no package-registry
upload or hosting service. Identify the final commit with a new v0.1.0 tag only
after its CI passes. Never move an existing tag to conceal a failed release.

Release completion requires the actual tag, release notes and successful CI
for the delivered commit. Passing local tests or preparing this document alone
does not establish publication. Scientific scope remains bounded by the
[audit](../release_audit.md) and [limitations](../limitations.md).
